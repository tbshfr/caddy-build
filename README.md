# caddy-build

Custom Caddy builds, each with its own set of plugins. When a tag is pushed, GitHub Actions builds them and posts them on the releases page.

| Binary | Plugins |
| --- | --- |
| `caddy-static-linux-amd64` | [caddy-static-adapter](https://github.com/tbshfr/caddy-static-adapter) |
| `caddy-netacl-linux-amd64` | [caddy-netacl](https://github.com/tbshfr/caddy-netacl) |
